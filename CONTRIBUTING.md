# Contributing to NeoDSE

Report bugs and request features in a [GitHub issue](https://github.com/RealisLux/NeoDSE/issues).
Include the version or commit, host distribution, architecture and steps to
reproduce, with secrets removed. Report vulnerabilities privately through
[SECURITY.md](SECURITY.md).

## Pull requests

Pull requests are welcome, but merging is not guaranteed: a change is accepted
only when it fits the project's direction. Open an issue first to discuss a
substantial change.

Prepare the change as described in [Make changes](docs/DEVELOPMENT.md#make-changes).
In the pull request, explain the problem, the change and how you tested it, and
list any checks you could not run and why.

Contributions use the project's [MIT License](LICENSE).
